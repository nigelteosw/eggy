Before changing code for an ambiguous request, settle what it should do.

1. Read the code that the request touches. Find the existing pattern and follow it.
2. If one reading is clearly right from the code, take it and say so in your summary.
3. If two readings lead to different changes, and the code cannot decide between them, ask the owner one specific question with ask_owner. Offer the options you can see.
4. Keep the change to what the request asks. Note adjacent problems in your summary instead of fixing them.
