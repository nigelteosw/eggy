Before you say a change is done:

1. Run the repository's checks with run_check, and read each exit code.
2. If a check fails, fix the cause. Do not weaken the check.
3. In your summary, list only the checks you actually ran and their results. Say plainly which checks you did not run.

A claim that something passes is only true if a check you ran says so.
