For a change that touches several files, write the plan into your working notes before editing:

1. List the files you will change, and what each change is for.
2. Order the steps so that each one leaves the code compiling.
3. Name the check that proves each step worked.

Then carry the steps out in order. If a step fails in a way the plan did not expect, stop, correct the plan, and continue. Do not keep going on a plan you know is wrong.
